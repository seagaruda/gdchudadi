# 锄大地(广东规则)的不完全信息博弈建模与最优策略求解

*基于信念状态、纳什均衡与信息集蒙特卡洛树搜索的单玩家视角研究 · 理论与实现研究稿 · 2026年10月*

## 摘要

锄大地(Big Two)是流行于中国大陆广东地区的四人扑克博弈,具有隐藏手牌、顺序决策、多人零和与可选择“过牌”等特点,是典型的**多人不完全信息扩展式博弈**。本文首先以联众游戏平台的规则为基准给出锄大地的形式化描述(广东地区通行玩法),并将规则差异参数化;其次建立完美回忆的扩展式博弈模型,估算状态空间规模;再从单个玩家的视角出发,将决策问题刻画为带信念状态的部分可观察决策问题(POMDP),给出贝叶斯信念更新公式与贝尔曼方程;然后从纳什均衡角度讨论解的存在性、计算复杂性与可利用度(NashConv)度量,给出基于抽象与反事实遗憾最小化(CFR)的蓝图策略;最后设计融合信念采样的信息集蒙特卡洛树搜索(ISMCTS)在线求解框架,并给出手牌拆分动态规划作为价值函数。本文还讨论了联众两两计分下的隐性联盟(合纵连横)问题;本文以方法与理论为主,并附带一个可运行的 Java 实现与初步实验(第9节),**实验结论仅限于启发式对手**,并给出完整的评估协议。

**关键词**:锄大地;不完全信息博弈;纳什均衡;反事实遗憾最小化;蒙特卡洛树搜索;信念状态

## 1 引言

完美信息博弈(围棋、象棋)已被深度搜索与自我强化攻克[5];不完全信息博弈则需要对对手隐藏信息进行推理。德州扑克、斗地主分别在两人与三人场景下有了成熟方法[8][9][10]。锄大地与它们的不同在于:(1)四人、非合作,无固定队友;(2)牌型比较含花色,组合空间约两万种;(3)结算由剩余牌数与倍率决定,收益非单纯胜负。目前针对其广东规则的系统性数学建模较少,本文试图补足。

本文贡献:

- 给出以联众平台规则为基准的参数化形式定义与动作空间规模;
- 建立单玩家视角的信念-决策模型,并与纳什均衡概念建立联系,讨论两两计分下的隐性联盟;
- 提出“CFR蓝图 + 信念采样ISMCTS + 拆牌价值函数”的求解框架,并分析其理论局限,给出可运行的 Java 实现与初步实验。

## 2 规则与记号

### 2.1 基本规则(本文约定)

- 一副牌52张(无王),4人各13张。点数大小:3 < 4 < 5 < … < 10 < J < Q < K < A < 2;花色大小:方块 < 梅花 < 红桃 < 黑桃。
- 单张牌的全序:记点数序号 r∈{0,…,12}(3→0,…,2→12),花色序号 s∈{0,1,2,3},牌序 o(c)=4r+s,o 越大牌越大。
- 持有**方块3**者在首副牌先出,且首轮出牌必须包含方块3;此后每副牌由上一副的获胜者先出,无需含方块3。本文的单局模型取首副牌情形。
- 逆时针依次出牌,必须出与上一手**同张数且更大**的牌,或选择**过牌**。连续三人过牌后,最后出牌者获得**出牌权**,可自由领出任意合法牌型。
- 最先出完手牌者获胜,其余三人按剩余牌数计牌分,再按 2.3 的公式两两结算。

### 2.2 牌型与动作空间规模

| 牌型 | 说明 | 实例数 |
|---|---|---|
| 单张 | 按牌序比较 | 52 |
| 对子 | 同点数两张,比较较大一张的牌序 | 78 |
| 三条 | 同点数三张 | 52 |
| 顺子 | 五张连续点数,共10个窗口(A2345、23456、3-7 至 10-A;A 不能在顺的中间) | 10,200 |
| 同花 | 五张同花色非顺,比最大一张 | 5,108 |
| 葫芦 | 三条加一对,比较三条点数 | 3,744 |
| 四带一 | 四条加任意一张 | 624 |
| 同花顺 | 五张同花色连续 | 40 |

合计 **19,898** 种可能的出牌实例。五张牌型强弱:顺子 < 同花 < 葫芦 < 四带一 < 同花顺;比较规则(联众):只有张数相同的牌才能比较,五张牌型之间按上述强弱;对子、三条、葫芦、四带一、顺子、同花都取其中最大的一张按单张方式比较(先点数、后花色),葫芦取三条中最大的一张,四带一取四条中最大的一张,同花不再比较次大牌(联众规则页未单列同花,按此通则处理)。顺子中2作小牌,A 与 K 相连时作大牌、与2相连时作小牌,A 不能在顺的中间,故 JQKA2 不是顺;A2345 取5比较,23456 取6比较。

### 2.3 规则参数向量 Θ

广东各地细则略有差异,本文以联众游戏平台的规则为基准,将可变部分抽象为参数 Θ,模型与算法对 Θ 保持不变,仅改变合法动作集与收益函数:

- Θ₁:是否允许三条单出(联众规则允许,本文取允许;不允许则删去52个实例);
- Θ₂:顺子窗口集合(联众规则10个窗口,含 A2345、23456;若某地不含这两个窗口,则相应删去);
- Θ₃:同花比较次序(联众规则:取最大一张按单张方式比较,先比点数、再比花色);
- Θ₄:结算倍率函数 m(n) 与黑桃2加倍规则(取联众规则,见下)。

本文采用联众游戏平台的牌分与结算([联众官网规则页](https://www.ourgame.com/game/cutout.html))。设某玩家在游戏结束时剩余 n 张,牌分 p(n)=n·m(n),其中 m(n)=1(n≤7)、2(8≤n≤9)、3(10≤n≤12)、4(n=13);若结束时手中仍有 8 张或更多牌且含黑桃2,牌分再乘以 2。赢家牌分为 0。玩家 i 的得分为其与另外三人牌分之差的总和:

```latex
u_i = \sum_{j \ne i} (p_j - p_i) = \sum_{j \ne i} p_j - 3\,p_i
```

故 Σᵢuᵢ=0,博弈为**零和**。官网算例:四家剩余 5、8、0、12 张,牌分为 5、16、0、36,得分为 37、-7、57、-87。注意非赢家也可能得正分,所以除了“谁先出完”,剩牌数与是否压着黑桃2同样进入效用。联众另有“100分一轮”玩法(牌分累计到100分才结算),本文不涉及。

另设 Θ₅:下家仅剩一张牌时,上家若出单张,只能出手中最大的单张;若桌面上一手为单张,且上家手中有单张能压过它,则上家不得过牌(过牌限制为本文补充设定);出对子等多张牌型不受此限。联众官网规则页未载明此条,依据是部分资料对联众世界锄大地的介绍,原始出处尚未核实;本文按此默认开启,关闭则退回无此限制的模型。

## 3 扩展式博弈模型

### 3.1 形式定义

博弈 G=(N, H, Z, P, A, ℐ, u):

- N={0,1,2,3} 为玩家集合,另有机会节点“发牌”:从 52!/(13!)⁴ ≈ **5.36×10²⁸** 种发牌中均匀抽取;
- H 为历史集合,一个历史包含发牌结果与此后的(玩家, 动作)序列;Z⊂H 为终局历史;
- P(h) 为在 h 处行动的玩家;A(h) 为合法动作集(出牌或过牌;领出时不能过牌;Θ₅ 开启时,若下家仅剩一张牌,出单张的动作只能是手中最大单张,且上一手为单张、手中有能压过它的单张时不得过牌);
- 信息集:玩家 i 在 h 处的信息集 Iᵢ(h) 由 (Cᵢ⁰, 公开出牌序列) 决定,其中 Cᵢ⁰ 为 i 的初始手牌。由于所有玩家都能记住自己手牌与全部公开动作,**博弈具有完美回忆**;
- 收益 uᵢ(z) 如 2.3 所定义。

### 3.2 隐藏信息规模

对任一玩家 i,开局时对手三手牌的未知分配数为 39!/(13!)³ ≈ **8.45×10¹⁶**。精确求解整棵博弈树不可行,必须依赖信念近似、抽象与采样。

## 4 单个玩家视角:信念状态与决策模型

### 4.1 信念状态

固定玩家 i。在时刻 t,设已出牌集合为 Dₜ,则未知牌集 Uₜ = 全牌 ∖ (Cᵢ(t) ∪ Dₜ),且 |Uₜ| = Σⱼ≠ᵢ nⱼ(t),其中 nⱼ(t) 为玩家 j 剩余张数。**隐藏状态**为对 Uₜ 的划分 x=(Xⱼ)ⱼ≠ᵢ,满足 |Xⱼ|=nⱼ(t)。

先验为均匀分布:

b₀(x) = 1 / ( |U|! / ∏ⱼ nⱼ! )

观测到公开动作序列后,由贝叶斯公式:

bₜ(x) ∝ 1[x 与全部已出牌一致] · ∏ₜ′≤ₜ, 行动者 j≠i σⱼ( aₜ′ | Iⱼ^{t′}(x) )

其中 σⱼ 是对手策略(未知,以模型 σ̂ⱼ 代替)。该式含两类信息:

1. **硬约束**:对手打出的牌必然在其原手牌中,已出牌不再属于任何人;
2. **软信息**:对手的选择(拆牌方式、是否过牌)偏向某些手牌结构。例如对手有能力压住却过牌,说明其可能在“留大牌/保存牌型”,似然降低。

### 4.2 信念 MDP 与贝尔曼方程

固定对手策略 σ₋ᵢ 后,i 面对的是 POMDP,等价于信念空间上的 MDP,状态为 (Cᵢ, 公开历史, bₜ):

V(s) = maxₐ∈A(s) { Σₒ P(o | s, a) · [ R(s, a, o) + V(s′) ] }

其中 o 为下一次轮到 i 前观察到的对手动作序列,终局 R 取 uᵢ。由于单局回合数有限(每局至多约几十步),该方程在有限视界内定义良好,但信念空间维度极高,故需 4.3 的采样近似。

### 4.3 信念的近似表示

- **粒子滤波**:维护 K 个满足硬约束的完整对手手牌假设 x⁽ᵏ⁾ 及权重 wₖ,每次观察到动作 a 后更新 wₖ ← wₖ·σ̂ⱼ(a | x⁽ᵏ⁾),并在有效样本量 ESS=(Σwₖ)²/Σwₖ² 过低时重采样;
- **约束采样**:对满足硬约束的划分,可通过逐家无放回(多元超几何)抽样生成;出现不可行时回退到 MCMC 交换两家的一对牌并检验一致性。

### 4.4 期望收益与最优策略

当前决策的行动价值:

Q(Iᵢ, a) = Σₓ bₜ(x) · E[ uᵢ | x, a, σ ]

单玩家最优策略 π\* 为对 σ₋ᵢ 的**最佳反应**:π\* ∈ argmax uᵢ(π, σ₋ᵢ)。这引出核心问题:σ₋ᵢ 取什么?若取对手的真实策略则是剥削(exploitation),若取均衡策略则是稳健(robust)。下一节讨论后者。

## 5 纳什均衡视角

### 5.1 存在性与非唯一性

**命题1**:G 为有限扩展式博弈且具有完美回忆,故存在行为策略纳什均衡 σ\*,使得对每个 i,σᵢ\* ∈ argmax uᵢ(σᵢ, σ₋ᵢ\*)。(Nash[1],Kuhn[2])

需要谨慎的是:

- 一般有限博弈中计算纳什均衡属于 PPAD-完全问题[7];
- 两人零和博弈存在极小极大保证、均衡策略可互换;**四人零和则没有这些性质**——不同均衡的玩家策略混搭后可能不再是均衡,处于均衡并不保证期望收益非负[10]。

因此在锄大地中,“求解纳什均衡”应被理解为得到**低可利用度的稳健策略**,而不是得到唯一最优解。

### 5.2 可利用度

定义 NashConv(σ) = Σᵢ [ maxσᵢ′ uᵢ(σᵢ′, σ₋ᵢ) − uᵢ(σ) ]。由零和性,Σᵢuᵢ(σ)=0,故 NashConv(σ) = Σᵢ maxσᵢ′ uᵢ(σᵢ′, σ₋ᵢ) ≥ 0,当且仅当 σ 为纳什均衡时取 0。它是评价策略稳健度的核心指标。

### 5.3 反事实遗憾最小化(CFR)蓝图

对信息集 I 与动作 a,累计反事实遗憾:

Rᵢᵀ(I,a) = Σₜ₌₁ᵀ [ vᵢ^{σᵗ}(I,a) − vᵢ^{σᵗ}(I) ]

遗憾匹配更新:σᵀ⁺¹(I,a) = Rᵀ,⁺(I,a) / Σₐ′ Rᵀ,⁺(I,a′)(若分母为0取均匀)。平均策略的收敛性:

- 两人零和:平均整体遗憾 ≤ Δ·|Iᵢ|·√|Aᵢ| / √T,平均策略为 ε-均衡[3];
- 多人博弈:平均策略仅收敛到**粗相关均衡**一类的解概念,无纳什保证,但实践中(如多人扑克[10])依然能产生强策略。

**抽象**是必须的,否则 19,898 种动作与 10¹⁶ 量级的信息集无法处理:

- 牌力抽象:用手牌特征向量(控制牌数、拆牌最少轮数、顺子/对子/单张结构)聚类为 B 个桶;
- 动作抽象:把同牌型中“大小差异无关紧要”的出牌合并,仅保留最小可压、中间、最大三档;
- 局面抽象:把对手剩牌数量压缩为 {1, 2, 3–4, 5–8, 9+} 等区间。

求得的抽象博弈策略称为**蓝图策略** σ_bp,用作开局决策与在线搜索的先验。

### 5.4 两两计分下的隐性联盟(合纵连横)

联众结算是两两比较,得分 uᵢ = Σⱼ≠ᵢ pⱼ − 3pᵢ。由此有三点后果:

- **目标是分差而不是名次**:例如我剩3张,A 出完,B 剩10张(牌分30),C 剩9张(牌分18),则 u = (0+30+18) − 3×3 = 39,小输 A 却大赢 B、C。
- **利益随局势分化**:终局时自己牌分的权重为 −3,别家牌分的权重各为 +1。剩牌少的玩家希望尽快结束,剩牌多的玩家(尤其 n≥8 且握黑桃2,牌分将翻倍)希望拖延、拦截领先者、尽早甩掉黑桃2。两个玩家在某一时刻可以利益一致(都想拦住快出完的 A),过一会儿又可能对立。
- **无望获胜者能左右谁赢**(kingmaker 问题):放水让谁出完,或卡住谁,会改变其余各家的得分,却不改变自己的牌分。

在模型里的位置:本文是非合作博弈,玩家间没有交流也没有可约束的承诺,所以“联盟”不是模型的原语,而是各自最优反应碰巧一致的结果(隐性联盟)。这有两点含义:

1. 效用已经包含上述全部权衡,4.2 节的贝尔曼方程与第6节的 ISMCTS 无需改动即可权衡“小输大赢”;实现中采用 max^n 回传[16][18],每个节点按出牌者自己的得分选动作。
2. 多人零和没有极小极大保证(5.1),均衡策略也不保证防住他人的默契配合;CFR 在多人博弈中只收敛到粗相关均衡一类的解(5.3)。所以面对真人的“合纵连横”,更现实的办法是对手建模(估计 σ̂ⱼ 中的放水、拦截倾向),而不是追求均衡。

若玩家可以交流,或一场牌连打多副并累计分数(如“100分一轮”),声誉、报复与互惠会成为新因素,需要重复博弈或合作博弈(特征函数形式[17])的工具,本文未建模。当前实现的模拟对手只是简单启发式,不含放水或拦截,因此对真人这类打法的估计会有偏(见 9.1)。

## 6 信息集蒙特卡洛树搜索

### 6.1 确定化与其缺陷

最朴素的方式是**完美信息蒙特卡洛(PIMC)**:从信念 bₜ 采样一个完整对手手牌 x(确定化),在完美信息博弈上用 UCT[4,5] 搜索,多次采样后汇总 a 的统计量。其已知问题:

- **策略融合**:搜索假设“知道对手手牌”,把需要在不同 x 下做出相同动作的决策拆开优化,高估了信息优势;
- **非局部性与信息泄露**:忽略自己的动作暴露信息、对手的反应基于信息集而非真实手牌[6][11]。

### 6.2 ISMCTS(单观察者)

为缓解上述问题,采用 ISMCTS[6]:树节点是**信息集**而非状态。每次迭代:

1. 从 bₜ 采样确定化 x,仅用于判断该次迭代中哪些动作合法;
2. 沿信息集树选择:对节点 v 的可用动作 a,最大化
   UCB(v,a) = Q(v,a) + c·√( ln N′(v,a) / N(v,a) )
   其中 N′(v,a) 为 a 在 v 可用的访问次数(可用性计数),N 为访问次数,c 为探索常数;
3. 扩展一个新节点,并以**滚动策略**走到终局:各玩家用蓝图策略 σ_bp 采样动作(而不是均匀随机),以降低方差与偏差;
4. 回传终局收益 uᵢ(z)(可归一化到 [0,1]);多人博弈中每个节点按该节点出牌者自己的得分选择动作(max^n 回传[16][18])。

最终选择访问次数最多的动作。

### 6.3 BP-ISMCTS 求解流程

```
输入: 当前信息集 Iᵢ, 蓝图 σ_bp, 迭代数 M, 粒子数 K
1. 用粒子滤波更新信念 {(x_k, w_k)}, 似然 = σ_bp(a|x)
2. for m in 1..M:
     x ← 按 w 从粒子采样一个确定化
     沿信息集树 UCB 选择; 扩展; 用 σ_bp 滚动到终局
     回传 u_i
3. 返回 argmax_a N(root, a)
```

- **时间复杂度**:O(M·D·B),D 为单局平均深度,B 为滚动单步动作生成开销(主要在合法动作枚举,可用位掩码与牌型预计算降至近似常数);
- **理论性质**:ISMCTS 不保证收敛到纳什均衡[6],因此本文把它定位为“蓝图的在线精修”,而非均衡求解器。

## 7 价值函数:手牌拆分动态规划

滚动与剪枝都依赖对手牌好坏的评估。定义 f(H) 为手牌集合 H 在**仅考虑自己出牌**时打完所需的最少回合数:

f(∅)=0, f(H) = min_{c⊆H, c 为合法牌型} [ 1 + f(H ∖ c) ]

该式可用状态压缩 DP 求解(13张手牌至多 2¹³=8192 个子集),计算量小,可在搜索内部反复调用。

但“回合数少”不等于“更容易赢”,还需要**控制权**:只有拿到出牌权才能把一回合用掉。定义手牌价值:

V(H) = −α·f(H) + β·κ(H) − γ·ω(H)

其中 κ(H) 为控制力(如手中 2、A、同花顺、四带一、大对子的数量及其能在对手手牌分布下压住对手的概率),ω(H) 为“孤立小单张数”(它们几乎必须靠别人让权才能打出)。α, β, γ 可通过自我对弈回归或手工调参确定。

在联众结算下,价值函数还要反映无望获胜时的止损:牌分 p(n) 在 n=8、10、13 处陡增,且 n≥8 时手握黑桃2会再翻倍,因此估值中应加入期望牌分项 −δ·E[p(n_T)],其中 n_T 为终局剩牌数。

## 8 残局分析与可解释的策略命题

在局面信息充分的残局,搜索可近似精确求解。给出一个可证的朴素结论。

**命题2(报单约束)**:设下家 j 仅剩1张牌,且我方拥有出牌权。若我方领出任何**多张牌型**(对子、三条、五张牌型),则 j 无法跟牌(只剩一张),必然过牌;若我方领出单张 c,则 j 有概率直接打出最后一张并获胜,其概率不小于 P[ o(j 的那张牌) > o(c) ]。

*证明概要*:j 仅一张牌,不可能满足多张牌型的张数要求;对单张则取决于牌序比较。证毕。

由此得到可检验的启发式:**下家报单时,应优先拆成多张牌型领出;必须领单张时,选能压过 j 所有可能剩牌的最大单张(或用信念估计其剩牌)**。这与职业玩家经验一致,并可作为搜索中的剪枝规则。

Θ₅ 默认开启,故下家报单时上家出单张必须出最大单张,这已是硬性规则而非启发式,搜索时可直接把该情形的单张动作集压缩为一个;若上一手为单张且压得过,过牌也被禁止,该决策点只剩这一个动作;领出多张牌型不受影响,命题2照常成立。

其他常见启发式也可用本文框架解释:

- **保存大牌控制权**:V(H) 中的 κ(H) 项;
- **拆牌代价**:拆开对子打单张会使 f(H) 上升,价值函数给出量化代价;
- **过牌的信息价值**:过牌既保留手牌,也向对手(及观察者)泄露能力,需要在似然 σ̂ⱼ(pass | x) 中显式建模。

联众的黑桃2条款还给出一条止损规则:当己方已无望获胜、终局剩牌可能达到8张以上时,应尽早打出黑桃2,避免牌分翻倍。

## 9 实现与初步实验

### 9.1 已完成的实现与测试

配套实现(Java 8 语法、无外部依赖,可直接放入 Android 项目)包含:规则引擎(位掩码手牌,19,898 种牌型实例的枚举与比较,Θ₅ 与联众结算)、SO-ISMCTS(第6节;每个节点按出牌者自己的联众得分选动作)和启发式滚动策略。与第6节设计的差别:滚动策略用启发式而非 CFR 蓝图 σ_bp(尚未实现 CFR),信念只用硬约束下的均匀采样,未实现 4.3 节的粒子滤波软更新。以下结果均来自桌面 JVM 21 单线程,**未在真机上测试**。

- **规则正确性**:全牌枚举得 19,898 种出牌实例(单张52、对子78、三条52、顺子10,200、同花5,108、葫芦3,744、四带一624、同花顺40),与 2.2 节一致;联众官网结算算例得分 37、-7、57、-87;3000 局随机对局均正常结束、牌守恒,且“报单后过牌 ⇒ 不持有更大的牌”这一公开推断无误。
- **速度**:约 17,600 次迭代/秒。
- **强度**:复式配对,即同一副牌里把某个座位从启发式 bot 换成 ISMCTS,座位轮换。200 副牌平均每副多得分:300 次迭代/步为 +5.0(标准误 1.2),1500 次迭代/步为 +5.8(标准误 1.4);两档之间的差异在误差范围内。

局限:对手是启发式 bot,且与 ISMCTS 模拟中的对手模型相同,结果偏乐观;对真人、对 CFR 蓝图或 DouZero 式基线的强度以及 NashConv 均未测;模拟中的对手不会放水或拦截(见 5.4)。

### 9.2 完整评估协议(尚待实施)

**以下为建议的完整评估协议,9.1 只完成了其中一小部分**,其余仍待实施:

## 10 结论与展望

本文把锄大地(广东规则)形式化为四人零和、完美回忆的不完全信息扩展式博弈,并从单玩家视角给出信念更新与贝尔曼方程,明确了“最佳反应(剥削)”与“纳什均衡(稳健)”的区别:由于多人零和博弈缺乏极小极大保证,**实用目标应是低可利用度而非精确均衡**。在算法上提出 CFR 蓝图加 ISMCTS 在线精修,并以拆牌动态规划提供价值函数。后续工作:(1)按 9.2 的协议完成完整评估(对 CFR 蓝图与真人的强度、NashConv 估计);(2)用对手建模在线估计 σ̂ⱼ 以实现自适应剥削;(3)引入神经网络价值与策略头替代手工 V(H),并在不同地区规则 Θ 间做迁移;(4)按 5.4 节对放水、拦截等隐性联盟行为建模。
